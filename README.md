# מאגר מיקומים דנאל

מערכת RTL לניהול אתרי עבודה ונקודות דיווח, בחלוקה לתחנות וקטעים.

## יכולות בגרסה הראשונה
- שער כניסה בעיצוב מאגר 610/911
- תפקידי בעלים ומנהל
- אתרי עבודה / נקודות דיווח
- תחנות / קטעים
- שם מיקום, ק״מ, קישור Waze, Google Maps, קואורדינטות והערות
- חיפוש, סינון, הוספה, עריכה ומחיקה
- פתיחה ישירה בניווט

> חשוב: המאגר נוצר כרגע כ-Public. יש לשנות אותו ל-Private לפני שמירת מידע תפעולי אמיתי.
