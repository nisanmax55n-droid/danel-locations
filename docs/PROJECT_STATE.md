# מצב הפרויקט — מאגר מיקומים דנאל

## מטרה וזהות המאגר

`danel-locations` הוא מאגר למערכת מאגר מיקומים: אתרי עבודה ונקודות דיווח, מסוג תחנה או קטע, עם ק״מ/טווח ק״מ, קישורי Waze ו־Google Maps, קואורדינטות והערות. קיימת גם הגשת בקשות מיקום בידי עובדים ובדיקתן בידי מנהלים.

מסמך זה הוא חפיפה עובדתית. לפני שינוי יש לאמת שוב את הקוד והנתונים הרלוונטיים; הוא אינו מחליף בדיקה.

## ארכיטקטורה

- חזית: React + TypeScript + Vite ב־`src/`; build דרך `npm run build`.
- שרת: FastAPI ב־`backend/main.py`; שכבת middleware ב־`backend/server.py`.
- מסד נתונים: SQLAlchemy; PostgreSQL כשהוגדר `DATABASE_URL`, וברירת מחדל SQLite מקומית.
- הזדהות: JWT נפרד למנהלים ולעובדים. תפקידי מנהל פנימיים: `owner` ו־`manager`.
- פריסה: Dockerfiles נפרדים ל־frontend ול־backend, וקובץ `railway.json`.
- Railway production: שירותי frontend, backend ו־Postgres פעילים. קוד וסודות הייצור אינם מוסקים מהמאגר.

## מקור האמת וזרימות

| תחום | מקור אמת מאומת |
| --- | --- |
| מיקומים מאושרים | טבלת `locations` |
| בקשות מיקום עובדים | טבלת `location_requests` |
| משתמשי מנהל | טבלת `users` |
| חשבונות עובדים | טבלת `employee_accounts` |
| תחנות נוסעים | רשומת התחלה מהקוד ב־`backend/passenger_stations.py`, שנזרעת למסד בעת עליית השרת |

- שמירת או עריכת מיקום, וכן הגשת בקשה, עוברת middleware שמנרמל קישור שיתוף מלא של Google Maps או Waze.
- מהקישור המנורמל נשמרים קואורדינטות ונוצרים קישור Waze וקישור Google Maps.
- בדיקת כפילות מאומתת לפי שם קטע מנורמל+ק״מ, או לפי נקודת יעד זהה. קטע בכיוון הפוך מטופל כשם קטע זהה.
- בקשת עובד נשמרת בנפרד עד לאישור או דחייה; היא אינה מיקום מאושר לפני פעולת מנהל מפורשת.

## בדיקות קיימות

`tests/test_locations.py` מכסה:

- המרת קישורי Google/Waze לשני סוגי קישורים.
- זיהוי כפילויות לפי שם/ק״מ ולפי נקודה.
- איחוד קטעים בכיוון הפוך.
